# Практична робота 1С
Розв’язання задачі лінійного програмування зі змішаною системою обмежень за допомогою модифікованих жорданових виключень

## Мета роботи

Навчитися розв’язувати задачу лінійного програмування зі змішаною системою обмежень з використанням симплекс-методу.

## Завдання

Розробити програму, яка на основі модифікованих жорданових виключень (МЖВ) виконує такі дії:

- Видалення нуль-рядків у симплекс-таблиці  
- Знаходження опорного розв’язку задачі лінійного програмування  
- Знаходження оптимального розв’язку задачі лінійного програмування  

### Зауваження 

Знак однієї із нерівностей системи обмежень необхідно змінити на протилежний.  
Номер нерівності, яку потрібно інвертувати, вказує викладач.

Необхідно описати структуру програми, вхідні й вихідні дані, навести екранні форми (screenshots) програми, а також продемонструвати виконання як тестових прикладів, так і власного варіанта завдання.
