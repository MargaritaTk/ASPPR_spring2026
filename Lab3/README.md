# Практична робота №3

## Розв’язання матричної гри з нульовою сумою. Моделювання матричних ігор. Матричні ігри 2×n та m×2

### Мета роботи
Навчитися розв’язувати і моделювати матричні ігри з нульовою сумою.

### Постановка задачі

Під час виконання практичної роботи необхідно:

1. Перевірити наявність розв’язку в чистих стратегіях для матричної гри 3×3 (матрична гра A1).  
Якщо розв’язку немає — знайти його в змішаних стратегіях шляхом розв’язання пари взаємно двоїстих задач лінійного програмування.
2. Розробити програму для моделювання результатів розв’язання матричної гри A1 за допомогою рівномірно розподілених випадкових чисел.
3. Перевірити наявність розв’язку в чистих стратегіях для матричної гри 2×2 (матрична гра A2).  
   Якщо розв’язку немає — знайти його аналітично і графічно.
4. Розв’язати матричну гру 2×n або m×2 (матрична гра A3) графічно-аналітичним методом, зводячи її до гри 2×2.
