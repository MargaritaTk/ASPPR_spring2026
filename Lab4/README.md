# Практична робота №4

## Ігри з природою

### Мета роботи
Навчитися знаходити оптимальні стратегії гравця в іграх з природою, використовуючи такі критерії прийняття рішень:
- Вальда (принцип максиміну)
- Оптимізму (принцип максимаксу)
- Гурвіца (принцип песимізму-оптимізму)
- Севіджа (принцип мінімаксу)
- Байєса та Лапласа

### Постановка задачі

Під час виконання практичної роботи необхідно розробити програму, за допомогою якої для заданої матриці корисності результатів U (згідно з варіантом завдання) можна визначити оптимальні стратегії гравця в грі з природою, використовуючи наступні критерії:

1. Критерій Вальда (принцип максиміну)  
2. Критерій оптимізму (принцип максимаксу)  
3. Критерій Гурвіца (принцип песимізму-оптимізму)  
4. Критерій Севіджа (принцип мінімаксу)  
5. Критерії Байєса і Лапласа

Треба Описати структуру програми, навести вхідні та вихідні дані, додати екранні форми (скріншоти) інтерфейсу програми, продемонструвати роботу програми на:
  - тестових прикладах
  - власному варіанті завдання
