# Практична робота №5
Розв’язання транспортної задачі

## Мета роботи
Навчитися розв’язувати транспортні задачі методом потенціалів.

## Постановка задачі

Під час виконання практичної роботи необхідно:

1. З’ясувати, до якої форми (відкритої або закритої) належить задана транспортна задача.  
   Якщо задача відкрита, ввести фіктивний пункт відправлення (ПО) або призначення (ПН).

2. Розробити програму, у якій для заданих матриць:
   - запасів (пункти відправлення — ПО),
   - заявок (пункти призначення — ПН),
   - вартостей перевезень (SP)

   реалізуються такі дії:
   - Пошук опорного плану перевезень методами:
     - Північно-західного кута
     - Мінімального елемента
   - Пошук оптимального плану перевезень методом потенціалів.
3. Дати постановку транспортної задачі як задачі **лінійного програмування**.
4. Побудувати симплекс-таблицю для транспортної задачі.
5. Розв’язати транспортну задачу симплекс-методом (підставити симплекс-таблицю в практичну роботу № 1.С).
6. Перевірити виконання завдання в Excel (Дані → Розв’язувач).
