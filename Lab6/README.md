# Практична робота №6

## Розв’язання задачі про призначення

### Мета роботи
Навчитися розв’язувати задачі про призначення угорським методом.

### Постановка задачі
Під час виконання практичної роботи необхідно:

1. Розробити програму, яка за допомогою угорського методу за заданою матрицею вартостей робіт буде призначати співробітників на конкретні види робіт.

2. Дати постановку задачі про призначення як задачі лінійного програмування.

3. Побудувати симплекс-таблицю для задачі про призначення.

4. Розв’язати задачу про призначення симплекс-методом (підставити симплекс-таблицю в практичну роботу № 1.С).

5. Перевірити виконання завдання в Excel (Дані → Розв’язувач).

### Вимоги до звіту

- Описати структуру програми
- Навести вхідні та вихідні дані
- Додати скріншоти (екранні форми) програми
- Продемонструвати роботу на тестових прикладах та власному варіанті завдання
