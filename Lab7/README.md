# Практична робота № 7

## Розв’язання задачі сіткового планування. Метод критичного шляху

### Мета роботи
Навчитися будувати сітковий графік робіт проекту та розраховувати його параметри методом критичного шляху.

### Завдання

Під час виконання практичної роботи необхідно розробити програму, яка дозволяє:

- Будувати сітковий графік робіт проекту
- Розраховувати параметри сіткового графіка:
  - Ранні терміни початку/завершення робіт
  - Пізні терміни початку/завершення робіт
  - Резерви часу (повний та вільний)
- Знаходити критичний шлях виконання робіт
- Обчислювати тривалість проекту (довжину критичного шляху)
- Будувати та оптимізувати календарний план робіт
- Будувати та оптимізувати графік завантаження людських ресурсів

Перевірити виконання завдання в онлайн-сервісі GanttPRO.

### Вимоги до звіту

- Описати структуру програми
- Навести вхідні та вихідні дані
- Додати скріншоти (екранні форми) програми
- Продемонструвати роботу на тестових прикладах та власному варіанті завдання
