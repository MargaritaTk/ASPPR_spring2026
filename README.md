# Практична робота #1 (Part A) 

Під час виконання практичної роботи необхідно розробити програму, за допомогою якої на основі звичайних жорданівських виключень можна реалізувати такі дії:

1. Пошук оберненої матриці для довільної квадратної матриці  
2. Обчислення рангу довільної прямокутної матриці  
3. Розв’язання системи лінійних алгебраїчних рівнянь за допомогою оберненої матриці (1-й спосіб)  
4. Розв’язання системи лінійних алгебраїчних рівнянь з попереднім приведенням її до вигляду **Ax – B = 0** (2-й спосіб)  
5. Розв’язання системи лінійних алгебраїчних рівнянь методом Гаусса (3-й спосіб)

## Вхідні та вихідні дані для кожного завдання

### 1. Обчислення оберненої матриці

**Вхідні дані:**
- `n` — розмірність квадратної матриці A  
- `A` — матриця вихідних значень (n × n)

**Вихідні дані:**
- `C` — обернена матриця до A

### 2. Обчислення рангу матриці

**Вхідні дані:**
- `n`, `m` — розмірність прямокутної матриці A  
- `A` — матриця вихідних значень (n × m)

**Вихідні дані:**
- `r` — ранг матриці A

### 3–5. Розв’язання системи лінійних алгебраїчних рівнянь

**Вхідні дані:**
- `n` — розмірність вектора невідомих X  
- `A`, `B` — матриці коефіцієнтів та вільних членів (згідно з варіантом)

**Вихідні дані:**
- `X` — вектор розв’язків (коренів) системи рівнянь

## Завдання для звіту

- Описати структуру програми
- Описати вхідні та вихідні дані
- Навести екранні форми 
- Продемонструвати роботу програми на:
  - кількох тестових прикладах
  - власному варіанті завдання
