# РР - Багатокритеріальна оптимізація з використанням теоретико-ігрового підходу

## Мета роботи
Навчитися розв’язувати задачі багатокритеріальної оптимізації з використанням теоретико-ігрового підходу.

## Завдання
Під час виконання індивідуального завдання необхідно розробити програму, за допомогою якої можна реалізувати такі дії:
1.	Розв’язати за допомогою симплекс-методу k задач лінійного програмування, у яких є одна цільова функція й загальна область обмежень.
2.	Побудувати матрицю мір неоптимальності кожного знайденого оптимального розв’язку до інших цільових функцій.
3.	Сформулювати ігрову задачу, де стратегіями поведінки першого гравця будуть оптимальні розв’язки для кожної цільової функції, а стратегіями поведінки другого гравця – цільові функції.
4.	Знайти розв’язок гри у змішаних стратегіях для першого гравця.
5.	Встановити значення вагових коефіцієнтів і розрахувати значення вектора компромісного розв’язку.

Необхідно описати структуру програми, вхідні й вихідні дані, навести екранні форми (screenshots) програми, а також продемонструвати виконання як тестових прикладів, так і власного варіанта завдання.
